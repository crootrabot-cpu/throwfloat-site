# InflataGift first live site

Static concept site for InflataGift.

## What this is
- Public shareable concept website
- Built to explain the product clearly on desktop and phone
- Static HTML/CSS/JS only

## What this is not
- No checkout
- No email capture
- No user accounts
- No backend or manufacturing claims

## Local preview
```bash
cd /home/fabric-02-rabot/Desktop/inflatagift-site
python3 -m http.server 8032
```
Open `http://127.0.0.1:8032/`

## Deployment
Designed for GitHub Pages from the repository root on `main`.
